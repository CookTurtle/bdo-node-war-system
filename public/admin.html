使用 Discord 登入

同步 Discord 可登入成員

依 Bot 讀取伺服器中擁有指定身份組的使用者，寫入可登入名單（普通成員）。管理員帳號不會被降級或刪除。
身份組 ID / 公會 ID 請在 functions/api/auth/[action].js 檔案頂部的 CONFIG_GUILD_ID、CONFIG_ROLE_IDS 修改（也可用環境變數覆蓋）。需已設定 DISCORD_BOT_TOKEN，且 Bot 已進服並開啟 Server Members Intent。


公會列表

先建立公會，新增成員時可從下拉選單指定所屬公會。刪除公會不會刪成員，只會清掉他們的公會欄位。

成員名單

AI 辨識家門名稱時會優先對照這份名單：讀到的名字與名單中某人只差一兩個字時，會修正成名單裡的寫法。名單以外的名字照原樣保留。
